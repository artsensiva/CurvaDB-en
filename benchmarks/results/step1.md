## 2. Честный фиттинг сплайна

Проверка: >= 10 точек густой сетки на каждый интервал между соседними точками ОЧИЩЕННОГО трека (после п.1), ошибка = point-to-segment расстояние до прямого сегмента между ними. Если s=0 (интерполяция) нарушает tol между какой-то парой точек — адаптивно добавляется synthetic-узел в месте максимального отклонения (до 8 раундов); затем растим `s` для компактности, сохраняя густую ошибку <= tol.

**ПОРОГ ПРИЁМКИ (>= 99% треков с густой ошибкой <= tol) ДОСТИГНУТ: 585/585 = 100.00% (параметризация временем).**

| Параметризация | Pass rate | Median err, м | p99 err, м | Max err, м | mean control points | треков с synthetic-узлами | bisect converged | время, с |
|---|---|---|---|---|---|---|---|---|
| time | 100.00% | 9.995 | 10.000 | 10.000 | 69.9 | 109/585 | 585/585 | 215.8 |
| chord | 100.00% | 9.935 | 10.000 | 10.000 | 59.5 | 105/585 | 585/585 | 188.3 |

Среднее число точек в очищенном треке: 242.6. Обе параметризации достигают одинакового pass rate; параметризация длиной хорды даёт заметно компактнее представление (59.5 vs 69.9 контрольных точек в среднем), но `derivatives()` (скорость/ускорение) реализована только для параметризации временем — нелинейная связь u<->t для хорды потребовала бы отдельной инверсии t(u), не нужной за пределами этого сравнения. Для кинематики (п.4) и остальных бенчмарков step1 используется параметризация временем (по умолчанию в fit()).

## 3. Recall@10 на треках с густой ошибкой <= 2·tol

На 585/585 очищенных треках с густой ошибкой сплайна <= 2·tol (30 запросов из этой же группы, корпус — все 585 треков): recall@10 DP = 0.993, recall@10 исправленного сплайна = 0.973 — против 0.997/0.707 в step0.md (сломанный фиттинг, без чистки данных).

## 4. Кинематика (гипотеза B): где сплайн выигрывает у DP

30 синтетических траекторий (разгон/торможение/поворот/стоянка, скорость непрерывна на стыках, seed=42), гауссов шум 5м на позицию, шаг 1..5с. Оценка в 759 точках (без первой/последней точки трека — краевой эффект у всех методов), из них |a_true| > 3 м/с² в 74 (9.7%). Калман: constant-acceleration + RTS, q=1 (подобран по RMSE ускорения на подвыборке из 8 треков).

| Метод | Ошибка v, м/с (median/RMSE) | Ошибка a, м/с² (median/RMSE) | Precision \|a\|>3 | Recall |
|---|---|---|---|---|
| исправленный сплайн | 1.521 / 3.145 | 0.795 / 3.882 | 0.159 | 0.284 |
| DP + PCHIP по вершинам | 2.316 / 4.087 | 0.919 / 248.150 | 0.205 | 0.338 |
| Калман (CA+RTS) | 1.253 / 2.268 | 0.647 / 1.701 | 0.833 | 0.068 |

Лучшая медианная ошибка скорости: Калман (CA+RTS). Лучшая медианная ошибка ускорения: Калман (CA+RTS).

Примечание: RMSE ускорения у DP + PCHIP заметно выше медианы (max ошибка 4991 м/с² против 33.6 у сплайна и 15.3 у Калмана) — численная хрупкость: если соседние вершины DP оказываются близко по времени (короткий отрезок между двумя точками разрыва DP), вторая производная PCHIP на этом отрезке может уходить в тысячи м/с². У Калмана обратная картина: лучшая ошибка (RMSE и медиана), но заметно ниже recall детекции |a| > 3 — сглаживание CA-модели подавляет резкие изменения ускорения (повороты), а не только шум.
