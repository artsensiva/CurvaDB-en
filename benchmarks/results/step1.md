## 2. Честный фиттинг сплайна

Проверка: >= 10 точек густой сетки на каждый интервал между соседними точками ОЧИЩЕННОГО трека (после п.1), ошибка = point-to-segment расстояние до прямого сегмента между ними. Если s=0 (интерполяция) нарушает tol между какой-то парой точек — адаптивно добавляется synthetic-узел в месте максимального отклонения (до 8 раундов); затем растим `s` для компактности, сохраняя густую ошибку <= tol.

**ПОРОГ ПРИЁМКИ (>= 99% треков с густой ошибкой <= tol) ДОСТИГНУТ: 585/585 = 100.00% (параметризация временем).**

|---|---|---|---|---|---|---|---|---|
| time | 100.00% | 9.995 | 10.000 | 10.000 | 69.9 | 109/585 | 585/585 | 215.8 |
| chord | 100.00% | 9.935 | 10.000 | 10.000 | 59.5 | 105/585 | 585/585 | 188.3 |

Среднее число точек в очищенном треке: 242.6. Обе параметризации достигают одинакового pass rate; параметризация длиной хорды даёт заметно компактнее представление (59.5 vs 69.9 контрольных точек в среднем), но `derivatives()` (скорость/ускорение) реализована только для параметризации временем — нелинейная связь u<->t для хорды потребовала бы отдельной инверсии t(u), не нужной за пределами этого сравнения. Для кинематики (п.4) и остальных бенчмарков step1 используется параметризация временем (по умолчанию в fit()).
