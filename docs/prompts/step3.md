# Step3 — решающий эксперимент

Контекст уже известен, НЕ запускай агентов-исследователей и не перечитывай
весь репозиторий: нужные файлы — src/traj/spline.py, src/traj/simplify.py,
benchmarks/step2_crossover.py, benchmarks/_report_utils.py,
benchmarks/results/step2.md. step0-2 не удалять, старый fit() не менять.

Причина step3: в step2 сплайн был привязан к ломаной — контракт fit()
требует держаться у прямых отрезков между отсчётами, поэтому сплайн
наследовал ошибку хорды (L^2/8R) и не мог сглаживать шум. Доли достижимых
треков у сплайна и DP совпадали во всех клетках (3/30, 25/30, 24/30, 26/30).

## Критерии (зафиксированы до запуска, не менять)

- К1 (сжатие): сплайн после zlib >= 30% меньше DP+SED хотя бы в двух клетках
  с sigma/tol <= 0.1 на переменной скорости, при достижимости >= 80% треков
  у обоих.
- К2 (реконструкция): при dt >= 5 с есть клетки, где сплайн достижим на
  >= 80% треков, а DP+SED на <= 20%.
- К3 (шум): при sigma = 5 есть tol, где сплайн достижим на >= 80%,
  а DP+SED на <= 20%.
