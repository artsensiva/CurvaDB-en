# P2. CertiInspect — контроль детали «скан против CAD» с сертифицированным отклонением

## 1. Продукт

**Что делает.** Принимает CAD-модель детали (STEP, B-rep с NURBS-гранями), облако точек со
сканера или координатно-измерительной машины и допуски (профиль поверхности по граням).
Совмещает облако с моделью, считает для каждой точки **интервал** отклонения от номинальной
поверхности со строгими границами, учитывает неопределённость измерения и выдаёт по каждой
грани решение «соответствует / не соответствует / не определено» по правилам ISO 14253-1.

**Кому.** Отделы контроля качества машиностроения, аэрокосмоса, медицинских изделий, литья и
аддитивного производства; метрологические лаборатории.

**Ценность.** Стандартные программы считают расстояние до **тесселированной** модели
(треугольной сетки). Ошибка тесселяции смешивается с отклонением детали; вблизи границы допуска
это даёт ложные решения. CertiInspect считает расстояние до точной NURBS-поверхности с
доказанной границей погрешности вычисления и явно разделяет погрешность вычисления,
неопределённость измерения и собственно отклонение.

**Существующие решения.** Коммерческие программы инспекции по облакам точек и открытые
инструменты сравнения облака с сеткой. **Отличие:** доказуемые интервалы расстояния до точной
поверхности и формальные решения о соответствии с учётом неопределённости.

**Границы v1.** Профиль поверхности (двусторонняя зона `±t/2`), базирование по трём базам
(плоскость, линия, точка) или наилучшее совмещение; без полного набора допусков GD&T
(позиционные, биения и т. п. — позже).

## 2. Математическая модель

### 2.1. Поверхности

Грань B-rep конвертируется в NURBS (`BRepBuilderAPI_NurbsConvert` в OpenCASCADE) и хранится
как `S(u, v) = Σ N_i(u) N_j(v) w_ij P_ij / Σ N_i(u) N_j(v) w_ij` с кривыми обрезки в
пространстве параметров (p-кривые) и трёхмерными рёбрами.

### 2.2. Строгий интервал расстояния: ветви и границы

Для точки `p` и грани `F`:

1. Грань разбивается на Безье-патчи (вставка узлов в обоих направлениях).
2. Очередь с приоритетом по нижней границе. Для патча:
   - `LB = dist(p, AABB(P_патча))` — строгая нижняя граница (свойство выпуклой оболочки при `w > 0`);
   - `UB = |p − S(u*, v*)|`, где `(u*, v*)` — результат 3–5 шагов Ньютона от центра патча,
     **только если** точка `(u*, v*)` лежит внутри области обрезки.
3. Патч делится де Кастельжо на 4 части, если `LB < UB_best − η`.
4. **Обрезка.** Патч в пространстве параметров классифицируется относительно многоугольника
   обрезки с сертифицированным расширением: «внутри», «снаружи» (отбрасывается), «граница»
   (делится). Для граничных патчей нижняя граница по оболочке остаётся строгой (подмножество).
5. **Рёбра.** Расстояние до трёхмерных рёбер грани считается тем же методом для кривых; итог
   `dist(p, F) = min(внутренняя часть, рёбра)`.
6. Остановка: `UB_best − LB_min ≤ η` (по умолчанию `η = 0.5 мкм`). Результат `[d_lo, d_hi]`.

Для всей детали: BVH по AABB граней, обход в порядке нижних границ.

### 2.3. Знак отклонения

Знак определяется не по нормали в ближайшей точке (неустойчиво у рёбер), а классификацией
точки относительно тела (`BRepClass3d_SolidClassifier`): «внутри материала» — минус,
«снаружи» — плюс. Если точка ближе `η` к поверхности, знак помечается как неопределённый.

### 2.4. Совмещение

- **Начальное:** RANSAC по признакам FPFH (Open3D) между облаком и точками, выбранными на
  поверхности модели.
- **Точное, наилучшее совмещение:** итеративное совмещение «точка — плоскость», где ближайшие
  точки и нормали берутся из строгого движка 2.2; робастная функция потерь Хьюбера; остановка по
  изменению преобразования `< 1e-9`.
- **Базирование по базам (A–B–C):** плоскость A — прилегающая по минимаксу (линейное
  программирование, `scipy.optimize.linprog`); B — ограниченная подгонка при фиксированной A;
  C — при фиксированных A и B.
- **Неопределённость совмещения:** ковариация параметров из матрицы Гессе задачи «точка —
  плоскость» плюс бутстрап по точкам (200 повторов); распространяется на отклонения.

### 2.5. Неопределённость и решение о соответствии

Для точки: `U_i = k · √(σ_scan² + σ_reg,i²)`, `k = 2`. Зона допуска профиля `[−t/2, +t/2]`.

- **Соответствие доказано** для грани, если для всех точек `d_hi,i + U_i ≤ t/2` и
  `d_lo,i − U_i ≥ −t/2`.
- **Несоответствие доказано**, если существует связная область площадью не меньше `A_min`
  (защита от выбросов), где `d_lo,i − U_i > t/2` или `d_hi,i + U_i < −t/2`.
- Иначе — **не определено**, с указанием зоны.

`σ_scan` задаётся паспортом сканера или оценивается по остаткам на гладких участках
(медианное абсолютное отклонение).

## 3. Базовый соперник

Расстояние от облака до тесселированной модели (сетка из OpenCASCADE при хордовых допусках
10 мкм и 1 мкм, вычисление через `trimesh` или `open3d.t.geometry.RaycastingScene`), знак по
нормали треугольника, то же совмещение и те же правила решения, но без интервалов вычисления.

## 4. Данные для проверки

1. **Аналитические эталоны:** сфера, цилиндр, тор, конус, плоскость с вырезами (обрезка),
   экспортированные в STEP и сконвертированные в NURBS. Истинное расстояние считается по
   формулам.
2. **Модели из набора ABC** (открытый набор CAD-моделей в STEP): 200 деталей с
   поверхностями свободной формы.
3. **Симулятор скана** с известной истиной:
   - деформация модели полем смещений по нормали: сумма радиальных базисных функций, амплитуда
     10–200 мкм;
   - выборка видимых точек из 6–12 направлений (трассировка лучей по мелкой сетке деформированной
     модели), 0.2–2 млн точек;
   - шум `σ ∈ {0, 2, 10, 30}` мкм, выбросы 0.1%, пропущенные зоны;
   - случайное твёрдотельное преобразование;
   - истинное отклонение каждой точки известно по построению.
4. **Сценарии допусков:** для каждой детали `t` выбирается так, чтобы у части граней запас был
   больше `3U`, у части — близок к нулю.

## 5. Архитектура

```
certiinspect/
  cad/step_reader.py        # OCP: чтение STEP, грани, NURBS-конверсия, p-кривые, рёбра
  cad/nurbs_extract.py      # полюса, узлы, веса → массивы numpy
  geom/bezier_patches.py    # выделение патчей (certigeo)
  geom/distance_bb.py       # ветви и границы, numba
  geom/trim.py              # классификация патчей относительно обрезки
  geom/bvh.py               # BVH граней
  geom/sign.py              # классификация «внутри/снаружи»
  register/global_init.py   # FPFH + RANSAC (Open3D)
  register/icp_certified.py # точка–плоскость с робастной потерей
  register/datums.py        # базирование A–B–C, линейное программирование
  uncertainty.py            # ковариация, бутстрап, U_i
  decide.py                 # правила 2.5
  sim/scan_simulator.py     # симулятор 4.3
  baseline/mesh_distance.py # соперник
  report/html.py            # тепловая карта по граням, таблица решений, JSON
  cli.py                    # certiinspect run part.step scan.ply --tol tol.yaml -o report/
```

## 6. Стек

Python 3.12; `OCP` (привязки OpenCASCADE, колёса `cadquery-ocp`) для STEP и топологии;
`numpy`, `numba`, `scipy` (KD-деревья, линейное программирование); `open3d` (совмещение,
ввод-вывод облаков); `trimesh` (соперник); `pyvista` (визуализация); `jinja2`; `python-flint`
(контрольные интервальные пересчёты); `pytest`, `hypothesis`; ядро `certigeo`.
Этап 2: ветви и границы на Rust.

## 8. Приёмка (не менять)

| № | Критерий | Порог |
|---|---|---|
| B1 | Корректность: истинное расстояние лежит в `[d_lo, d_hi]` | 100% из ≥ 10⁶ точек на аналитических эталонах; на ABC — против эталона высокой точности (`mpmath`, глобальный поиск) на 10⁵ точек |
| B2 | Ширина интервала `d_hi − d_lo` | ≤ 0.5 мкм для ≥ 99.9% точек |
| B3 | Восстановление заложенной деформации | при `σ = 0` ошибка ≤ 1 мкм вне зон 0.5 мм у рёбер; при `σ > 0` СКО ≤ 1.1·σ |
| B4 | Совмещение без шума | поворот ≤ 1e-4°, сдвиг ≤ 0.1 мкм для детали 100 мм |
| B5 | Решения о соответствии на 500 сценариях с известной истиной | ноль неверных решений «соответствует/не соответствует»; доля «не определено» ≤ 15% среди граней с запасом > 3U |
| B6 | Сравнение с соперником | у соперника при хордовом допуске 10 мкм есть неверные решения в сценариях с малым запасом, у CertiInspect — ноль; время ≤ 5× соперника |
| B7 | Производительность | 2 млн точек, деталь из 100 граней ≤ 10 мин на 6 ядрах |

**Остановка.** Если B6 не показывает ни одного неверного решения соперника при реалистичных
допусках и хордовых допусках тесселяции, преимущество не доказано — продукт не имеет отличия,
направление пересматривается (возможна ниша только для сверхточных допусков).

## 9. Тесты свойств (обязательные)

- Для случайных точек и патчей: `LB ≤` расстояние по плотной выборке `≤ UB`.
- Инвариантность: одинаковое преобразование детали и облака не меняет интервалы.
- Монотонность: нижняя граница дочернего патча не меньше нижней границы родителя (контрольные
  точки потомка лежат в оболочке родителя), лучшая верхняя граница не растёт по ходу поиска.
- Точки на поверхности дают `d_lo ≤ 0 ≤ d_hi` в пределах `η`.
- Решение «соответствует» никогда не выдаётся, если хотя бы одна точка с истинным отклонением
  вне зоны допуска (на синтетике).

## 10. Риски

- **Колёса OpenCASCADE для Python** требуют совместимой версии Python — зафиксировать 3.12.
- **Обрезка и вырожденные грани** в реальных STEP (швы, полюса сфер) — отдельный набор
  регрессионных моделей.
- **Неопределённость сканера** на практике сложнее модели `σ` — в v1 параметр, в v2 калибровка.
- **Консервативный рынок метрологии** — для внедрения нужна валидация с аккредитованной
  лабораторией; до этого — интервью и пилот на неответственных деталях.
