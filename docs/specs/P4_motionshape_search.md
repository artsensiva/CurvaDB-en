# P4. MotionShape — поиск движений по форме и кинематике, инвариантный к положению

## 1. Продукт

**Что делает.** Хранит библиотеку трёхмерных траекторий (движения робота, маркеры захвата
движения, манёвры дронов, росчерки пера) и ищет движения, **похожие по форме**, независимо от
того, где, в какой ориентации, в каком масштабе и с какой скоростью они выполнялись. Отдельно
поддерживает поиск по кинематическому профилю (скорость вдоль пути).

**Кому.** Робототехника (поиск демонстраций для обучения, повторное использование траекторий),
спортивная и медицинская биомеханика, анимация и захват движения, анализ манёвров беспилотников.

**Ценность.** Поиск по координатам находит только движения в том же месте и той же ориентации.
Поиск по форме находит «тот же жест» или «тот же манёвр» в любом месте.

**Существующие решения.** Динамическое выравнивание времени (DTW), упругий анализ форм через
SRVF (есть открытые библиотеки), методы на основе нейросетевых эмбеддингов. **Отличие:**
строго инвариантные метрики с устойчивым к шуму внутренним представлением и индексом с
измеренной полнотой.

**Предупреждение.** Спрос не подтверждён. Разработка дальше этапа M2 — только после интервью
(порог 3 из 10). Технически это направление наиболее близко к гипотезе H2 из CurvaDB.

## 2. Математическая модель

### 2.1. Устойчивое сглаживание

Координаты `r(t)` сглаживаются кубическим сглаживающим сплайном с параметром, согласованным с
шумом: `s = n · σ²`, где `σ = 1.4826 · MAD(Δ²x) / √6` (вторые разности независимого шума имеют
дисперсию `6σ²`, множитель 1.4826 переводит медианное абсолютное отклонение в СКО; оценка
верна при равномерном шаге, иначе вторые разности берутся с весами по шагу). Затем кривая перепараметризуется по длине
дуги и дискретизируется в `M = 256` точек. Урок CurvaDB: сглаживание задаётся шумом, а не
допуском по максимуму.

### 2.2. Метод A: SRVF с вращением (упругая метрика)

Функция `q(s) = r'(s) / √|r'(s)|`. Длина кривой нормируется к 1, тогда `‖q‖ = 1`
(предформа на сфере). Упругое расстояние:

```
d_A(r1, r2) = min_{R ∈ SO(3), γ} arccos ⟨q1, √γ' · (R q2) ∘ γ⟩
```

Оптимизация попеременно: вращение — решение задачи Прокруста (SVD, алгоритм Кабша, с запретом
отражений); перепараметризация `γ` — динамическое программирование на сетке `M × M` с
ограничением наклонов. 3–5 итераций. Инвариантность к сдвигу (через производную), вращению,
масштабу (нормировка), перепараметризации (`γ`) выполняется по построению.

### 2.3. Метод B: кривизны в параллельной рамке (рамка Бишопа)

Кручение Френе `τ = (r' × r'') · r''' / |r' × r''|²` неустойчиво при малой кривизне. Вместо него
используется **рамка без вращения** (параллельный перенос нормали вдоль касательной):
`T' = k1 N1 + k2 N2`, где `N1, N2` переносятся без вращения. Функции `k1(s), k2(s)` определены и
непрерывны даже при нулевой кривизне, а `κ = √(k1² + k2²)`.

Выбор начальной нормали произволен с точностью до постоянного поворота в нормальной плоскости,
поэтому сигнатура `z(s) = k1(s) + i · k2(s)` определена с точностью до множителя `e^{iφ}`.
Расстояние:

```
d_B(r1, r2) = min_{φ, γ} ‖ z1 − e^{iφ} (z2 ∘ γ) · √γ' ‖
```

При фиксированной `γ` оптимальная фаза находится в замкнутом виде: `φ* = arg ⟨z1, z2∘γ⟩`.
Перепараметризация — динамическое программирование. Сигнатура уже инвариантна к сдвигу и
вращению; масштаб — нормировкой длины (кривизны умножаются на длину). Для двумерных данных
`k2 ≡ 0`, сигнатура — знаковая кривизна.

Производные берутся аналитически из сглаживающего сплайна (раздел 2.1); это единственное место,
где гладкость сплайна обязательна.

### 2.4. Кинематический канал

Профиль скорости `v(τ) = |r'(t)|`, время нормировано к `[0, 1]`, скорость — к средней.
Сравнение — DTW с окном Сако–Чиба 10% и нижней границей LB_Keogh для отсечения.

### 2.5. Индекс

1. **Грубые инвариантные признаки** (размерность 32): гистограммы `κ` и `|k1|, |k2|` по
   длине, общая абсолютная кривизна `∫κ ds`, отношения главных моментов инерции облака точек,
   спектр мощности `|z|` на низких частотах.
2. Поиск ближайших по признакам через HNSW (`hnswlib`), кандидатов `C = 200`.
3. Точное упругое расстояние (метод A или B) только для кандидатов.
4. Полнота каскада **измеряется** против полного перебора (строгой нижней границы для упругих
   метрик по этим признакам нет — это честно отражено в критериях).

## 3. Базовые соперники

1. DTW по координатам после центрирования (`tslearn`) — не инвариантен к вращению.
2. DTW по координатам после выравнивания главных осей (PCA) — частичная инвариантность, известные
   неоднозначности знаков осей.
3. SRVF-упругое расстояние из открытой библиотеки `fdasrsf` — сильный соперник метода A.

## 4. Данные для проверки

1. **Синтетические трёхмерные манёвры** с известным классом: 12 классов (спираль, восьмёрка,
   петля, змейка, дуга с подъёмом и т. п.), по 200 экземпляров; случайное твёрдотельное
   преобразование, масштаб 0.5–2, нелинейная деформация времени, шум 0.1–3% размера, прореживание.
2. **Character Trajectories** (репозиторий UCI): двумерные росчерки пера по 20 буквам — проверка,
   что инвариантность не разрушает различимость.
3. **Захват движения CMU** (Graphics Lab Motion Capture Database): траектории маркеров кисти и
   стопы по размеченным действиям.
4. **Поворотные тесты:** одна и та же траектория в 1000 случайных ориентациях и масштабах.

```
motionshape/
  preprocess/smooth.py      # 2.1, оценка шума, сглаживающий сплайн, длина дуги

  repr/bishop.py            # 2.3, рамка без вращения, сигнатура z(s), фаза, DP
  repr/kinematic.py         # 2.4, DTW + LB_Keogh

```

## 8. Приёмка (не менять)

| № | Критерий | Порог |
|---|---|---|
| D1 | Инвариантность | изменение расстояния ≤ 1e-6 относительно при случайных вращениях, сдвигах, масштабе на 1000 парах |
| D2 | Точность 1-NN на синтетике со случайной ориентацией | ≥ лучший соперник − 1 п.п. и ≥ DTW по координатам + 10 п.п. |
| D3 | Character Trajectories, 1-NN | не хуже DTW по координатам более чем на 2 п.п. |
| D4 | Устойчивость к шуму | при шуме 1% размера точность падает ≤ 5 п.п. |
| D5 | Каскад | полнота@10 ≥ 0.99 против полного перебора; p95 запроса ≤ 100 мс на библиотеке 50 000 траекторий |

**Остановка.** Если D2 не выполнен ни методом A, ни методом B — инвариантный поиск не даёт
преимущества над соперниками, направление закрывается. Если интервью после M2 не дают 3 из 10 —
разработка останавливается на M2 с публикацией результатов.

## 9. Тесты свойств (обязательные)

- Для винтовой линии `k1² + k2²` совпадает с аналитической кривизной `a/(a² + b²)` до 1e-6.
- Постоянная `φ` в сигнатуре компенсируется оптимальной фазой точно.
- `d(r, r) = 0`, симметрия, неравенство треугольника для метода A (выборочно, допуск 1e-6).
- Перепараметризация кривой не меняет расстояние сверх погрешности DP.
- Сглаживание: на кривой без шума отклонение от исходной ≤ 1e-3 размера.

## 10. Риски

- **Спрос не подтверждён** — главный риск, закрывается интервью до M3.
- **Производные высокого порядка и шум** — метод B может проиграть методу A на реальных данных;
  это ожидаемый и приемлемый исход, критерии сформулированы для лучшего из двух.
- **Полнота каскада без строгой границы** — поэтому она измеряется и отчитывается, а не
  обещается.
