# Step7 (направление B). Сертифицированное хранилище кривых с интервальными запросами

## 1. Суть и место в проекте

**Идея.** Каждая сохранённая кривая `A` хранится как приближение `A′` (ломаная, сплайн или
гибрид) вместе с **доказанной** границей `ε_A ≥ d_F(A, A′)`, где `d_F` — непрерывная метрика
Фреше. Любой запрос по приближениям возвращает не число, а гарантированный интервал, в котором
лежит истинное расстояние между исходными кривыми.

**Отличие от P3 CertiTrack.** P3 — продукт на ломаных с упором на масштаб. Step7 —
исследование: сертификаты для **любого** представления, включая B-сплайны, у которых нет точного
алгоритма Фреше, и измерение того, насколько плотными получаются сертификаты у каждого
представления. Результаты step7 затем используются в step8 (гибрид) и в P3.

**Научные вопросы.**

1. Можно ли строго и плотно сертифицировать `d_F` между ломаной и сплайном?
2. Какая доля запросов решается по приближениям без чтения исходных данных при каждом
   представлении?
3. Сколько ошибок дают запросы по приближениям **без** сертификатов (цена отказа от гарантий)?

**Уроки CurvaDB, встроенные в задание.** Непрерывная метрика вместо дискретной (step0);
гарантия доказывается для всей кривой, а не в точках (step0–step1); ошибка меряется до истины на
синтетике (step2–step3); критерии зафиксированы до запуска (step3).

## 2. Математическая модель

### 2.1. Обозначения

- `A` — исходная ломаная с вершинами `V_0…V_n` (для синтетики дополнительно известна истинная
  кривая `A*`; сертификаты считаются относительно `A`, отдельно отчитывается `d_F(A*, A′)`).
- `A′` — приближение: (а) ломаная DP+SED из подмножества вершин; (б) LSQ-сплайн
  (`src/traj/spline_lsq.py`); (в) гибрид из step8.
- `d_F` — непрерывная метрика Фреше; для ломаных вычисляется алгоритмом Альта–Годау.

### 2.2. Сертификат для ломаной (точный)

Для `A′` из подмножества вершин `A`: `d_F(A, A′) = max_k d_F(A[i_k..i_{k+1}], [V_{i_k}, V_{i_{k+1}}])`,
каждая часть решается за линейное время. Сертификат — бисекция по решению с точностью
`η = 1 мм`, берётся верхний конец: `ε_A = hi`.

### 2.3. Сертификат для сплайна: монотонное проекционное сопоставление

Точного алгоритма Фреше для пары «ломаная — сплайн» нет, поэтому строится **явное монотонное
сопоставление** и доказывается граница его стоимости. Стоимость любого монотонного
сопоставления — верхняя граница `d_F`.

1. **Точки сопряжения.** Для каждой вершины `V_k` находится параметр `u_k` (ближайшая точка
   сплайна, Ньютон от предыдущего `u_{k−1}`), требуется `u_0 = 0 ≤ u_1 ≤ … ≤ u_n = 1`.
   Остаток `δ_k = |C(u_k) − V_k|` (верхняя граница вычисляется интервально).
2. **Кусок против отрезка.** Для куска `C[u_k, u_{k+1}]` и отрезка `S_k = [V_k, V_{k+1}]` с
   единичным направлением `e_k`:
   - кусок раскладывается на Безье-сегменты вставкой узлов в `u_k, u_{k+1}` и внутренних узлах;
   - **условие трубки:** все контрольные точки каждого Безье-сегмента лежат в капсуле радиуса
     `ρ_k` вокруг прямой-отрезка `S_k` (капсула выпукла, значит в ней весь кусок);
   - **условие монотонности:** все контрольные точки производной каждого Безье-сегмента
     (`p · (P_{i+1} − P_i)`) имеют `⟨·, e_k⟩ ≥ 0` — тогда проекция `s(u) = ⟨C(u) − V_k, e_k⟩`
     не убывает.
3. **Сопоставление.** Точке `C(u)` ставится в соответствие `V_k + clamp(s(u), 0, L_k) · e_k`.
   Оно монотонно по построению. Непокрытые начало `[0, s(u_k)]` и конец отрезка
   `[s(u_{k+1}), L_k]` сопоставляются концевым точкам куска.
4. **Граница стоимости.** Внутренние точки: расстояние до зажатой проекции не больше расстояния
   до капсулы-отрезка, то есть `≤ ρ_k`. Концевые хвосты: не больше
   `max(δ_k, δ_{k+1}, |s(u_k)| + δ_k, |L_k − s(u_{k+1})| + δ_{k+1})`.
   Итог: `ε_A = max_k max(ρ_k, хвосты_k)` плюс запас на округление `64 · ε_machine · L`.
5. **Уточнение.** Если условие монотонности или трубки не выполняется на сегменте, он делится
   де Кастельжо (до 12 уровней). Если не выполняется и после деления (сплайн делает петлю
   относительно отрезка), сегмент помечается «не сертифицирован» и траектория получает
   сертификат через запасной путь 2.4.

### 2.4. Запасной путь: сертифицированная линеаризация

Сплайн `A′` линеаризуется в ломаную `Lin(A′)` с шагом, при котором каждый Безье-сегмент лежит в
капсуле радиуса `λ` вокруг своей хорды и монотонен вдоль неё (тот же тест 2.3). Тогда
`d_F(A′, Lin(A′)) ≤ λ`, а `d_F(A, Lin(A′))` вычисляется точно (Альта–Годау). По неравенству
треугольника `ε_A = d_F(A, Lin(A′)) + λ`. Путь всегда применим, но дороже и чуть грубее.

### 2.5. Интервальные запросы

Для запроса `q` с приближением `q′` и сертификатом `ε_q`, кандидата `A`:

```
D = d_F(Lin(q′), Lin(A′))                          (точно, Альта–Годау)
d_F(q, A) ∈ [D − ε_q − λ_q − ε_A − λ_A,  D + ε_q + λ_q + ε_A + λ_A]
```

(для ломаных `λ = 0`). Запрос по диапазону `r` использует решения вместо расстояний:
принять, если `decide(D ≤ r − Σε)`; отбросить, если не `decide(D ≤ r + Σε)`; иначе уточнить по
исходным. Перед этим — строгие нижние границы из P3 (концы, прямоугольники).

**Оценка плотности сертификата.** Точное `d_F(A, A′)` для сплайна неизвестно, поэтому плотность
оценивается пессимистично через строгую нижнюю границу
`LB = max(max_k dist(V_k, A′), max_j dist(C(ũ_j), A))` по плотной выборке `ũ_j`
(направленный Хаусдорф в обе стороны). Отношение `ε_A / LB` не меньше истинного.

## 3. Соперники и контрольные варианты

1. **Полный перебор** точным решением по исходным ломаным — эталон ответа.
2. **Фильтр без сжатия:** концы + прямоугольники + точное решение по исходным — эталон скорости.
3. **Приближённый поиск без сертификатов:** решение по `Lin(A′)` с порогом `r` как есть.
   Отчитываются его пропуски и лишние ответы — это количественная цена отказа от гарантий.

## 4. Данные

1. **GeoLife очищенный** (все сегменты после `clean.py`, не только 585).
2. **Синтетика step3** (`benchmarks/step3_decisive.py`): дороги с клотоидами, переменная скорость,
   `σ ∈ {0, 0.1, 1, 5} м`, `dt ∈ {1, 5} с`; известна истинная кривая.
3. **Почти-дубликаты у границы:** копии траекторий с контролируемыми искажениями, для которых
   `d_F` к оригиналу вычислено заранее; запросы строятся так, чтобы часть ответов лежала в
   пределах `±2Σε` от `r` (самый трудный режим для интервалов).

## 8. Приёмка (не менять)

| № | Критерий | Порог |
|---|---|---|
| S1 | Корректность сертификатов ломаных | `ε_A ≥ d_F(A, A′)` (эталон `mpmath`, точность 1e-6 м) для 100% траекторий |
| S2 | Корректность сертификатов сплайнов | `ε_A ≥ d_F(A, Lin(A′, 1e-4 м)) − 1e-4 м` для 100% траекторий (почти точный эталон через очень мелкую линеаризацию) |
| S3 | Плотность | медиана `ε_A / LB` ≤ 1.2 для ломаных и ≤ 2 для сплайнов; доля сплайнов, ушедших в запасной путь 2.4, ≤ 10% |
| S4 | Точность запросов | 0 пропусков и 0 лишних против полного перебора: 1000 запросов × `r ∈ {50, 200, 1000} м` × все представления, включая почти-дубликаты |
| S5 | Решено без исходных | ≥ 80% кандидатов после пространственного фильтра хотя бы для одного представления при `r = 200 м` |
| S6 | Накладные расходы | сертификат ≤ 16 байт на траекторию; время запроса ≤ 2× приближённого поиска без сертификатов |

Дополнительно отчитывается (без порога): доля пропусков и лишних ответов у приближённого поиска
без сертификатов при тех же `r`.

**Остановка.** Если S5 меньше 50% для всех представлений — интервалы слишком широки,
сертифицированное хранилище не даёт выигрыша над фильтром без сжатия; направление закрывается,
вывод публикуется. Если S3 для сплайнов хуже 5 — сплайны исключаются из хранилища, остаются ломаные.

## 9. Тесты свойств (обязательные)

- Альт–Годау: `decide(ε)` согласовано с расстоянием; симметрия; неравенство треугольника
  (допуск 1e-9); `d_F` ломаной с её собственной перепараметризацией (добавлены вершины на
  отрезках) равно 0.
- Вставка узла и выделение Безье не меняют кривую (≤ 1e-12 · L).
- Для случайных сплайнов с выданным сертификатом: явное сопоставление, выбранное с шагом
  1e-4 по параметру, имеет стоимость ≤ `ε_A`.
- Монотонность проекции проверяется независимо по плотной выборке для каждого сертифицированного
  сегмента.
- Интервал из 2.5 содержит точное расстояние между исходными ломаными на 10 000 случайных парах.

## 10. Риски

- **Петли сплайна относительно отрезка** ломают монотонность — закрыто запасным путём 2.4,
  доля отчитывается (S3).
- **Широкие интервалы у границы `r`** — ожидаемо, доля уточнений отчитывается; это и есть
  главный научный результат.
- **Квадратичная стоимость Альта–Годау** на длинных треках — сегментация после `clean.py` и
  предварительные фильтры.
