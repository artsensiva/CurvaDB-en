# Step8 (направление A). Гибридное представление с явными особыми точками

## 1. Суть и место в проекте

**Идея.** Четыре шага CurvaDB показали одно и то же: ломаная дёшево описывает прямые и углы,
сплайн тратит параметры на изломы, но потенциально выигрывает на плавных дугах. Вместо выбора
одного представления кривая режется в **особых точках** (резкие повороты, остановки, разрывы
записи), и на каждом участке выбирается более дешёвое из двух: ломаная DP+SED или сплайн. Точки
разреза хранятся явно; в терминах B-сплайнов это узлы кратности `p`, где допускается излом.

**Научный вопрос: закрыть гипотезу H1.** В step3 оракул использовал только равномерные узлы,
поэтому вопрос «может ли сплайн с хорошей расстановкой узлов сжимать лучше DP+SED на точных
данных» остался открытым. Step8 отвечает на него двумя способами: практическим гибридом и
оракулом со свободными узлами.

**Зависимость.** Использует сертификаты из step7 (`certify.py`) для строгой проверки ошибки
относительно исходной кривой. Если step7 не выполнен, этапы M0–M2 можно проводить с проверкой на
густой сетке против истины, но итоговая приёмка H1 требует сертификатов.

**Честный прогноз.** Выигрыш на гладкой синтетике вероятен, на потребительском GPS маловероятен.
Даже 30% экономии байт — научный результат, а не продукт (вывод CurvaDB). Ценность step8 в том,
чтобы закрыть H1 определённо, в любую сторону.

## 2. Математическая модель

### 2.1. Кандидаты в особые точки

По исходной кривой `A` (вершины `V_k`, времена `t_k`) и её ломаной DP+SED с малым допуском
`tol/4`:

- **поворот:** угол между соседними отрезками ломаной `> θ_c` (сетка `θ_c ∈ {20°, 35°, 50°}`);
- **остановка:** средняя скорость на окне 3 отсчётов `< v_stop = 0.5 м/с`, особые точки — вход и
  выход из остановки;
- **разрыв записи:** `Δt > 3 · медиана Δt` (крупные разрывы уже режет `clean.py`);
- **скачок оценки кривизны:** на сглаживающем сплайне с `s = n σ²` строгая верхняя граница
  кривизны на Безье-сегменте больше `κ_c = 1 / R_min` (`R_min` — параметр, по умолчанию 20 м).

Кандидаты объединяются, близкие (ближе `2 · tol` по длине дуги) сливаются. Начало и конец кривой
всегда кандидаты. Итог — множество `K = {c_0 = 0 < c_1 < … < c_m = n}` индексов вершин.

### 2.2. Стоимость участка

Для участка `A[c_i..c_j]` считаются два кандидата с одинаковым требованием точности:

- **линия:** DP+SED на участке с подбором внутреннего допуска (как в step3), итог — вершины и
  времена;
- **сплайн:** кубический LSQ-сплайн `x(t), y(t)` на участке с минимальным числом узлов, узлы
  подбираются **удалением узлов** (2.4).

Требование точности: сертификат `ε ≤ tol` относительно исходного участка (step7), для синтетики
дополнительно отчитывается ошибка до истинной кривой. Стоимость — байты после единого кодирования
(2.5). `cost(i, j) = min(bytes_line, bytes_spline)`; если ни один не укладывается — `∞`.

### 2.3. Оптимальный разрез: динамическое программирование

```
F(0) = 0
F(j) = min_{i < j, j − i ≤ W} F(i) + cost(c_i, c_j) + header
```

`W` ограничивает число подряд идущих кандидатов в одном участке (по умолчанию 8), `header` —
байты заголовка участка. Сложность `O(m · W)` вычислений стоимости; стоимости кэшируются.
Разрезы в кандидатах, не выбранных программой, отбрасываются. Результат оптимален среди разрезов
по множеству `K`, а не глобально, — это оговаривается в отчёте.

### 2.4. Удаление узлов (свободные узлы без полного перебора)

Для сплайнового участка: начать с интерполирующего или плотного LSQ-сплайна, затем жадно
удалять узел, удаление которого меньше всего увеличивает сертифицированную ошибку, пока ошибка
`≤ tol` (схема удаления узлов в духе Лихе–Мёркена; после каждого удаления — перефит МНК с
оставшимися узлами). Кратность узла в граничных точках участка равна 3 (излом разрешён).
Остановка, когда любое удаление нарушает допуск.

### 2.5. Единое кодирование (одинаково для всех методов)

Поток участков: `[тип (1 бит), число элементов (varint)]`, далее для линии — вершины и времена,
для сплайна — внутренние узлы по времени и контрольные точки; координаты квантуются до 1 см,
время до 10 мс, дельта-кодирование внутри участка, общие граничные точки между участками не
дублируются; весь поток сжимается `zlib` уровня 9. Ровно та же схема применяется к «чистой»
ломаной DP+SED и «чистому» сплайну, чтобы сравнение было честным.

### 2.6. Оракулы

- **Сплайн-оракул со свободными узлами:** удаление узлов (2.4) на **истинной** кривой, без шума и
  разреженности. Это заметно более сильный потолок, чем равномерный оракул step3, но всё ещё не
  глобальный оптимум (жадность) — оговаривается.
- **Гибрид-оракул:** 2.1–2.3 на истинной кривой.

## 4. Данные

1. **Синтетика step3** с тем же генератором и seed: `σ ∈ {0, 0.1, 1, 5} м`,
   `tol ∈ {0.5, 2, 10} м`, `dt ∈ {1, 5} с`, 15 треков (при бюджете — 30).
2. **Синтетика с «чистыми» углами:** городские кварталы (прямые и повороты 90° с радиусом 5–10 м) —
   режим, где ожидается выигрыш ломаной; гибрид не должен здесь проигрывать.
3. **GeoLife очищенный:** 585 треков step1, `tol ∈ {2, 10} м`.

## 8. Приёмка (не менять)

Обозначение: клетка «пригодна», если оба сравниваемых метода достижимы на ≥ 80% треков.

| № | Критерий | Порог |
|---|---|---|
| A1 | Сжатие гибрида на гладкой синтетике | байты гибрида ≤ 0.70 × DP+SED хотя бы в двух пригодных клетках с `σ/tol ≤ 0.1` |
| A2 | Отсутствие проигрыша на реальных данных | GeoLife: байты гибрида ≤ 1.10 × DP+SED при каждом `tol` |
| A3 | Проверка H1 (потолок) | оракул со свободными узлами ≤ 0.80 × DP+SED (без шума, `dt = 1 с`) хотя бы в одной пригодной клетке |
| A4 | Корректность | для 100% итоговых представлений всех методов сертификат step7 `≤ tol` |
| A5 | Доминирование выбора | в каждой пригодной клетке гибрид ≤ 1.05 × `min(DP+SED, LSQ-свободные узлы)` |
| A6 | Кварталы с углами | гибрид ≤ 1.05 × DP+SED |

**Правило вывода по H1 (записывается в step8.md дословно по результату):**

- A3 не выполнен → «H1 закрыта: даже сплайн со свободными узлами на идеальной кривой не
  компактнее DP+SED на 20% в проверенных условиях».
- A3 выполнен, A1 не выполнен → «Потолок есть, но практическое построение по данным его не
  достигает».
- A1 выполнен, A2 выполнен → «Гибрид даёт выигрыш на гладких точных данных и не проигрывает на
  GPS».
- A5 или A6 не выполнены → динамическое программирование или кандидаты работают неверно;
  вывод по H1 не делается до исправления.

**Остановка.** Если после M1 A3 не выполнен — этап M2 выполняется в сокращённом объёме (только
контроль A5, A6), H1 закрывается, направление завершается публикацией вывода.

## 9. Тесты свойств (обязательные)

- Кодирование обратимо: декодирование восстанавливает представление с точностью квантования.
- На кривой, состоящей только из прямых, гибрид выбирает только линии и совпадает по байтам с
  DP+SED с точностью до заголовков.
- На окружности без шума гибрид выбирает сплайн и не хуже LSQ-свободных узлов более чем на размер
  заголовка.
- Удаление узлов никогда не возвращает представление с ошибкой больше `tol` (сертификат).
- Динамическое программирование на малых примерах совпадает с полным перебором разрезов.
- Инвариантность байтов к сдвигу кривой (при квантовании от первой точки).

## 10. Риски

- **Разрыв производной в точках разреза** ухудшает кинематику — для сжатия допустимо, фиксируется
  в отчёте как ограничение.
- **Жадное удаление узлов не глобально оптимально** — отчитывается как оговорка к A3; при
  «почти выполнен» (0.80–0.85) допускается один дополнительный прогон с перебором порядка
  удаления на 3 треках, записанный в отчёте.
- **Время расчёта** стоимостей участков — кэширование, ограничение `W`, пилот.
